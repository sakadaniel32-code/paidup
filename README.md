# Paidup (working name)

A simple quote → invoice → paid app for freelancers and small businesses.

- Home: how much you're owed, who's late, what needs you
- Type a sentence ("bill Kemi's Kitchen ₦160k for 20 designs") to create a quote or invoice
- Send on WhatsApp, auto-written reminders (polite / firm / abeg o)
- Quote → accepted → invoice in one tap, record payments
- Branded client view with Accept and bank-transfer Pay
- Logo, brand colour, currency, bank details in Settings

Prototype: data is saved in the browser on this device (no account yet). Backend (Supabase) comes next.
